# Customizable Interactions

## Definition

Customizable Interactions measures **how far beyond basic click-through slides an author can go** — including custom drag-and-drop, hotspot, timeline, accordion, simulation, and game-like interactions. This criterion captures both the breadth of available interaction types and the depth of customization possible within or beyond those types.

**Why it matters**: Passive content consumption produces minimal learning retention. Interactive elements increase engagement and learning transfer. Complex scenarios (software simulations, sales roleplay, compliance decision trees) require rich interaction capabilities.

## Key Insight

> **Articulate Storyline and Lectora represent a categorically different capability level** — they are programming environments for interactions, not just authoring tools. A developer with JavaScript can extend either platform to build anything a browser can render. The other tools in this comparison are authoring tools with pre-defined interaction patterns.
>
> **Parta.io's custom CSS blocks** bridge the gap for front-end designers: while not as powerful as Storyline's trigger system, the ability to write custom CSS gives designers layout and style control far beyond template-bound tools.
