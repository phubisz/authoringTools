# Collaboration Options

## Definition

Collaboration options encompass the ability for **multiple authors to work together on course content simultaneously or asynchronously** — including real-time co-editing, review/feedback workflows, role-based permissions, task assignment, and stakeholder comment management. In modern L&D, distributed authoring and SME involvement make collaboration capabilities a critical differentiator.

**Why it matters**: Teams without strong collaboration features resort to emailing files, version conflicts, and review bottlenecks. Cloud-native real-time collaboration reduces production cycles from weeks to days.

## Key Insight

> **The cloud-native tools have fundamentally redefined collaboration expectations.** Parta.io and Easygenerator offer simultaneous real-time co-authoring comparable to Google Docs — a capability that Articulate Storyline (desktop) still cannot match even with a Teams plan. Organizations with distributed authoring teams should prioritize cloud-native tools for this reason.

## Tool Commentary

### Parta.io
Built collaboration-first from day one. Multiple authors edit the same course in real time with cursor presence, inline comments, task assignment, and Kanban project boards. This is genuinely differentiating — Articulate reportedly took 10+ years to develop comparable features.

### Easygenerator
Google Docs-style co-authoring is a core selling point. Particularly effective for **SME-powered authoring** where non-L&D employees contribute content with L&D oversight. Comment and approval workflows manage the review cycle without email.

### Elucidat
Designed for large enterprise content production workflows: role-based access (Author, Reviewer, Publisher), simultaneous co-editing, centralized brand governance, and sign-off workflows. Strongest option for organizations with formal content governance requirements.

### dominKnow
Cloud-native real-time collaboration with shared asset libraries and change tracking. Combined with its advanced authoring capabilities, dominKnow is the only tool in this comparison offering both enterprise collaboration AND complex interaction design at the same level.

### Articulate 360
Review 360 is an excellent stakeholder feedback tool. However, Storyline remains a desktop application — simultaneous co-editing of a .story file is not supported. Rise 360 (cloud) is more collaborative. Teams plan is required for collaboration features.

### Gomo Learning
Team-based cloud authoring with role-based access. Not as mature as Parta.io or Easygenerator for real-time simultaneous editing, but solid for distributed review and approval workflows.

### Mindsmith
Teams tier adds multi-user access and brand controls. Collaboration features are newer and less mature than dedicated collaboration-first platforms. Good for small teams; less suited for large distributed authoring operations.

### iSpring Suite
Desktop-first architecture is the fundamental constraint. Files are shared via shared drives or version control. iSpring Learn (companion LMS) adds team management at the LMS level but not within the authoring tool itself.

### Lectora
Lectora Online provides web-based access, enabling some team collaboration. However, real-time co-authoring is not a documented feature. Review workflows exist but are not a primary product strength.
