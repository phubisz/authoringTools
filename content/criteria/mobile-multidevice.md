# Mobile / Multi-Device Compatibility

## Definition

Mobile / Multi-Device Compatibility measures how well a tool's **output renders and functions across smartphones, tablets, and desktop browsers** — including whether responsive design is automatic or requires manual configuration, and how well the authoring environment itself works on non-desktop devices.

**Why it matters**: Mobile learning (mLearning) is now standard in corporate training. BYOD policies, deskless workers, and global learner populations require content that works on any screen size without degradation. Flash-era desktop-only content is a compliance and engagement liability.

## Key Insight

> **Gomo Learning and Elucidat treat responsive design as a core architectural decision**, not a publishing option. Content is authored mobile-first — there is no "publish for mobile" step because mobile is the default. This contrasts with desktop tools like iSpring Suite and early Lectora versions where mobile compatibility was retrofitted.
>
> **Articulate Rise 360 achieves 5/5** because it is inherently a responsive block-based tool. Storyline's responsive output via the Modern Player is strong but can require adjustments for complex custom interactions.
