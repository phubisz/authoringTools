# Lectora

## Overview

Lectora is one of the **oldest and most powerful eLearning authoring tools**, developed by ELB Learning. It is renowned for its "no-compromise" approach: accessibility compliance (Section 508, WCAG), deep scripting, and complete design control. Lectora offers both a desktop (Lectora Desktop) and online version (Lectora Online), and is now sold as part of ELB Learning's **Learning Creation Studio** bundle, which includes 7+ tools such as CenarioVR (VR learning) and Rehearsal (video practice).

## Application

- **Ideal for**: Experienced instructional designers, compliance-driven organizations, accessibility-mandated content, complex branching scenarios
- **Use cases**: Section 508-compliant training, software simulations, scenario-based learning, regulatory compliance, VR-adjacent content
- **Not ideal for**: New authors, teams prioritizing speed over depth, organizations wanting AI-native rapid creation

## Criteria Ratings

### Collaboration Options ⭐⭐⭐ (3/5)
Lectora Online provides cloud-based access and some team sharing. Real-time co-authoring is limited compared to [[tools/parta-io|Parta.io]] or [[tools/dominknow|dominKnow]]. Review workflows exist but are not as polished as [[tools/articulate-360|Review 360]]. Desktop version is siloed by nature. See [[criteria/collaboration-options]].

### LMS Publishing Options ⭐⭐⭐⭐⭐ (5/5)
Comprehensive publishing: **SCORM 1.2, SCORM 2004, xAPI, AICC, HTML5, and PENS**. One of the broadest LMS compatibility records in the industry. Supports adaptive learning via SCORM variables. See [[criteria/lms-publishing]].

### Customizable Interactions ⭐⭐⭐⭐⭐ (5/5)
Tied with [[tools/articulate-360|Storyline]] for deepest customization. Action/condition system (scripting layer) enables complex logic. Supports JavaScript and API access. Custom widgets, multimedia layers, and fully free-form page layout (not slide-constrained). Extensive accessibility customization including keyboard navigation control. See [[criteria/customizable-interactions]].

### Learning Curve / Usability ⭐⭐ (2/5)
The steepest learning curve in this comparison. The action/condition system, page hierarchy, and publishing options require significant training. Lectora has historically targeted experienced IDs who want full control, not beginners. AI Course Wizard mitigates this for initial drafts. See [[criteria/learning-curve-usability]].

### Prebuilt Templates ⭐⭐⭐ (3/5)
Fewer polished out-of-the-box templates compared to [[tools/articulate-360|Articulate 360]] or [[tools/ispring-suite|iSpring Suite]]. Community templates exist but the ecosystem is smaller. Strength is in flexibility to build custom templates, not consume pre-built ones. See [[criteria/prebuilt-templates]].

### Mobile / Multi-Device Compatibility ⭐⭐⭐⭐ (4/5)
Responsive course output via HTML5. Lectora Online is mobile-accessible for authoring. Some legacy desktop features require careful mobile testing. Responsive design controls are available but less automatic than [[tools/gomo-learning|Gomo Learning]]. See [[criteria/mobile-multidevice]].

### Multilingual and Localization Scalability ⭐⭐⭐⭐ (4/5)
Strong localization support: RTL language handling, external text file export for translation, XLIFF support. Variable-driven content switching can support in-course language selection. Accessibility features align with international accessibility standards. See [[criteria/multilingual-localization]].

### LLM Ingestion Readiness ⭐⭐⭐ (3/5)
**AI Course Wizard** generates initial course drafts from prompts, creating a structural scaffold to refine. The underlying architecture is desktop/legacy-first, making deep LLM integration less natural than cloud-native tools. AI content generation is an accelerator, not the core product. See [[criteria/llm-ingestion-readiness]].

### Advanced Logic and Assessment Capabilities ⭐⭐⭐⭐⭐ (5/5)
Industry-leading logic capabilities:
- Condition/action scripting system
- Complex branching trees with multiple variables
- Question banks, adaptive testing, remediation paths
- JavaScript integration for unlimited extension
- Superior accessibility in assessments (keyboard navigation, screen reader support)
See [[criteria/advanced-logic-assessment]].

### AI Features ⭐⭐⭐ (3/5)
- AI Course Wizard: generates initial course draft from content outline
- AI-assisted content suggestions
- Limited compared to [[tools/mindsmith|Mindsmith]] or [[tools/articulate-360|Articulate AI Assistant]]
- ELB Learning roadmap is expanding AI capabilities
See [[criteria/ai-features]].
